# Year 1 High School Latin — Curriculum Outline

Henle-inspired, original sequence. Classical pronunciation. Grammar first, with Roman Empire context in every unit.

**Design:** many short lessons (≈10–20 min). Each unit ends with a **checkpoint** lesson (mixed review; must meet standard to unlock the next unit).

**Estimated load:** ~28–32 weeks of school-year pace (≈4–5 short lessons/week), or self-paced. Roughly **120–140 lessons** including checkpoints and culture segments — adjustable as we write content.

**Notation**

- **G** = grammar / forms focus  
- **V** = vocabulary heavy  
- **T** = translation / reading  
- **C** = Roman context  
- **R** = review / checkpoint  

**Shipped content (app):** Units **0–25** complete — **120 lessons** covering a full Henle First Year–aligned arc (original content, not copyrighted Henle text). Unlock-all is on by default for personal pacing.

**Every lesson** (see product doc): stated **standard** + teach + seed activities + AI may add more **Activity** objects (grids, translates, etc.) until the standard is met.

---

## Course outcomes (end of Year 1)

By the end of the course the student should be able to:

1. Pronounce Latin with **classical** norms (vowels, consonants, stress; macrons as a reading aid).
2. Decline nouns of **all five declensions** in common use and state major **case uses**.
3. Decline common **1st/2nd** and **3rd** adjectives; make nouns and adjectives **agree**.
4. Use core **pronouns** (personal, *hic/ille*, *qui*, *is/ea/id*).
5. Conjugate regular verbs in **1st–4th conjugations** in the **indicative**: present system + perfect system (active; passive where Year 1 typically introduces it).
6. Handle **sum / possum** and high-frequency irregulars introduced in Year 1.
7. State and use **principal parts** as a habit.
8. Read and write **short connected Latin** (sentences → brief paragraphs) within known grammar.
9. Place language work in a basic **map of Roman history and life** (Republic → early Empire, institutions, daily life, army, provinces).

## Vocabulary policy

- **Target:** roughly **350–450** high-frequency lemmas across Year 1 (not 1,000 busywork words).
- Every unit lists a **core set** (must master) and **support set** (recognition).
- Recycling: later units intentionally reuse earlier vocab in new grammar frames.
- Principal parts required for all verbs once the perfect system begins (Unit 9+).

Exact word lists can live in `content/vocab/` when authoring begins.

## Activity mix by lesson type

### Two default reps: endings + translation

Students will **add endings constantly** *and* **translate constantly** (both directions). Neither is a one-off worksheet line.

| Mode | Pattern | Adaptive? |
|------|---------|-----------|
| Forms | Grids, stems + endings, single slots; same endings, new lemmas | Template/shuffle heavy |
| Translation | Word → phrase → sentence; L→E and E→L | **AI grade + guidance + more items until standard** |

| Lesson type | Prefer |
|-------------|--------|
| New paradigm (G) | **Grid first**, then **translate ladder** using those forms (phrase → sentence) |
| Forms review | Grids on **prior** paradigms; a few single-slot blitz items |
| Syntax (G/T) | Short MC/identify + **translate** sentences hitting the case use |
| Translation day (T) | Seed L→E and E→L set; **adaptive follow-ups** until bar met |
| Culture (C) | English context + short Latin captions/mottoes to translate; reflection |
| Checkpoint (R) | Grids on all paradigms so far **+** mixed translation both ways; required bar must pass |

**Suggested progression inside a grammar unit**

1. Full paradigm grid (scaffolded → free)  
2. New lemma, same endings  
3. Translate words/phrases that use those forms  
4. Translate full sentences both directions  
5. If below standard → AI remediation items (same construction) until pass  

**Translation standard (default for a G/T lesson)** — tune per lesson when authoring:

- Seed items: e.g. 2–4 L→E and 1–3 E→L at target length `passed`, **or** equivalent passed count including generated remediation  
- Word-level gloss drills can be required early in a unit; sentence-level required by unit checkpoint  

AI tutor available on every lesson; culture lessons still allow grammar questions that spiral back.

## What Year 1 deliberately postpones (Year 2+)

Keep Year 1 honest; don’t cram a college survey.

- Subjunctive mood (full treatment)
- Indirect statement (*acc. + inf.*) deep dive (brief recognition optional at end if student is strong)
- Gerunds/gerundives
- Conditional full system
- Full deponent system (mention high-frequency deponents only if needed)
- Extensive poetry meter
- Unadapted Caesar as a course requirement (adapted snippets OK in Unit 21)

## Implementation order (content writing)

When building the app content, write in this order so the product loop is real early:

1. **Unit 0** (onboarding + pronunciation)  
2. **Unit 1** (first full mastery loop: declension + *sum*)  
3. **Unit 2–3** (verbs + 2nd declension)  
4. Fill forward along the outline; keep checkpoints strict
