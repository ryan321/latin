## Reflexive forms

### 3rd person (no nominative)

| Case | Form |
|------|------|
| Gen | suī |
| Dat | sibi |
| Acc | **sē** (or sēsē) |
| Abl | **sē** (or sēsē) |

*Puer **sē** videt.* — The boy sees **himself**.  
*Puer **eum** videt.* — The boy sees **him** (someone else).

### 1st / 2nd person

Use ordinary personal forms as reflexives:

- *Ego **mē** laudō.* — I praise myself.  
- *Tū **tē** servās.* — You save yourself.  
- *Nōs **nōs** armāmus.* — We arm ourselves.
